Model Evaluation: Experimental Setup
Evaluation environment and parameters

All benchmarked models were fine-tuned and evaluated on identical hardware to ensure strict baseline fairness. Final checkpoint metrics were rigorously captured.

  • Hardware Suite: 1x NVIDIA RTX 4090 GPU (24GB VRAM)
  • Training Framework: HuggingFace TRL (SFTTrainer) + PEFT
  • Dataset Split: 80% Train, 20% Holdout validation (~5,000 CS instruction-response pairs)
  • Inference Config: Temperature=0.7, Top-p=0.9, Top-k=50

Top Performers: Model Scale Impact

Based on the comprehensive evaluation metrics, the LLaMA-2-7B significantly outperforms the smaller 4B, 3B, and 2B models. Consistent with scaling laws, higher model capacity yields superior predictive Accuracy, lower cross-entropy Loss, enhanced predictive discriminability (higher ROC/AUC), and robustly lower predictive deviation (lower MSRE). This seamlessly translates into practical benchmark superiority across BLEU, ROUGE-L, and correctness (Pass@1).
